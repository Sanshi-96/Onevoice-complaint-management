# OneVoice – AI-Assisted Smart Complaint Management System

A final-year academic project developed as part of the Bachelor of Information Technology at the University of Moratuwa, Sri Lanka.

> **Repository scope:** This repository contains the frontend only. Backend source code, database credentials, and private configuration files are excluded.

## Project Overview

OneVoice is designed to improve public complaint management by providing a centralized digital platform connecting citizens, responsible authorities, and administrators.

The project addresses challenges such as fragmented complaint reporting, limited transparency, and difficulties tracking complaint progress.

## Objectives

- Simplify the complaint submission process.
- Improve visibility into complaint progress.
- Support communication between citizens and responsible authorities.
- Provide role-based interfaces for different user groups.
- Explore AI-assisted interaction and digital emergency reporting.

## Key Features

The frontend includes interfaces for:

- Public homepage and navigation
- Citizen, Authority, and Administrator portals
- Manual and voice-assisted complaint submission
- Complaint status tracking and authority remarks
- Dashboards and complaint reports
- Notification interfaces
- Chatbot assistance
- SOS emergency reporting

**Note:** The availability of a screen or interface does not mean its backend service is active in this frontend-only deployment. Features requiring authentication, persistent storage, email services, or external integrations need a connected backend.

## Technology Stack

- React.js
- JavaScript
- Vite

- REST API integration in the frontend, where applicable

## Run Locally

### Prerequisites
- Node.js (LTS version recommended)
- npm
- Git

### Installation

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd onevoice-complaint-management-frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

### Production Build

```bash
npm run build
npm run preview
```

## Project Scope and Limitations

This repository is intended to showcase the OneVoice frontend and its user-interface design. Backend services and database integration are not included. Consequently, live authentication, complaint persistence, email notifications, and external emergency-reporting integrations may be unavailable in the deployed demo.
